# Algorithm change logs

Thư mục này ghi lại các thay đổi về thuật toán, khác với runtime log trên UI.

Runtime log trả lời câu hỏi nằm trong tab `Log` của frontend. Còn thư mục này dùng để mô tả vì sao đổi pipeline, đổi ở đâu, kỳ vọng metric nào tăng và rủi ro nào cần kiểm tra.

## Gợi ý format cho mỗi lần đổi

```text
Ngày:
Tên thay đổi:
File liên quan:
Giả thuyết:
Metric cần cải thiện:
Kết quả:
Quyết định:
```
